### 4. Fixed date timezone bug (due_date)
- **Root cause**: Kolom `due_date` di DB type `date`. PostgreSQL driver ngembaliin sebagai `Date` object di local timezone. JSON serialize jadinya UTC. Frontend pake `.split('T')[0]` ambil tanggal UTC, jadinya mundur 1 hari.
- **Fix**: `task.due_date.split('T')[0]` → `new Date(task.due_date).toLocaleDateString('en-CA')`
