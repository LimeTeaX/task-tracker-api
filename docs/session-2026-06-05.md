### 4. Fixed date timezone bug (due_date)
- **Root cause**: Kolom `due_date` di DB type `date`. PostgreSQL driver ngembaliin sebagai `Date` object di local timezone. JSON serialize jadinya UTC (`"2026-06-03T17:00:00.000Z"` untuk `2026-06-04` di UTC+7). Frontend pake `.split('T')[0]` ambil tanggal UTC, jadinya mundur 1 hari.
- **Fix**: `task.due_date.split('T')[0]` → `new Date(task.due_date).toLocaleDateString('en-CA')` (format YYYY-MM-DD di local timezone)
